## 🔬 What is SKILL//X?

Most job platforms give you buzzwords, hallucinated salary calculators, and generic AI chatbots. 

**SKILL//X is different.** It is built like a high-density financial research terminal or bioinformatics workbench for human capital. Grounded exclusively in real-world labour market datasets, SKILL//X bridges macro industry demand with micro practitioner capability.

## ⚡ The Six Intelligence Modules

### `01` MARKET PULSE (`#skill-radar`)
- **Empirical Market Demand**: Direct telemetry parsed from **15,841 Indian tech job postings**.
- **Radar Topology**: Dynamically plotted SVG radar displaying market prevalence, posting counts, and emerging skill velocities.
- **Geographic Metros**: Filter by monitored hubs (Bengaluru, Mumbai, Pune, Hyderabad, Delhi NCR, Chennai).

### `02` SKILL GENOME (`#skill-genome`)
- **Topological Co-Occurrence**: Interactive mathematical network showing how skills cluster together in production environments.
- **Jaccard Normalization**: Edge weights reflect empirical co-occurrence likelihood, filtering out spurious correlations.
- **Focal Skill Inspection**: Click any node (Python, SQL, AWS, Docker, PySpark) to isolate its immediate graph neighborhood.

### `03` CAREER SUCCESS (`#career-success`)
- **Junior Data Scientist Predictive Engine**: Trained and validated on the JDS practitioner dataset ($N=692$).
- **Five Technical Dimensions**:
  1. Mathematics & Statistics (importance: +1.22)
  2. Dashboard & Storytelling (importance: +0.80)
  3. AI & Machine Learning (importance: +0.69)
  4. Big Data Systems (importance: +0.65)
  5. Production Coding (importance: +0.48)
- **Deterministic Holdout Accuracy**: **85.8% Balanced Accuracy** on unseen test partitions.

### `04` SENIOR SUCCESS (`#senior-success`)
- **Senior Data Scientist Predictive Engine**: Calibrated on the SDS practitioner dataset ($N=805$).
- **Big Five Personality Dimensions (0–100 Scale)**:
  - Conscientiousness (Methodical delivery & reproducibility)
  - Openness to Experience (Algorithmic experimentation)
  - Extraversion (Cross-partner coordination)
  - Agreeableness (Collaborative research orientation)
  - Neuroticism (Composure in non-deterministic systems)
- **Holdout Benchmark**: **92.8% Balanced Accuracy** on holdout evaluation.

### `05` CAREER SCAN (`#career-scan`)
- **Holistic Synthesizer**: Ingests target role, target geographic hub, continuous skill ratings, and psychometric profiles.
- **Comprehensive Dossier**: Generates an instant synthesis fusing market posting availability, junior hike probability, and senior profile alignment.

### `06` COPILOT (`#copilot`)
- **Factual Analytical Terminal**: Not a free-wheeling LLM. A grounded intelligence agent wired directly to statistical dataset aggregators.
- **Evidence Provenance**: Every response provides citations from the underlying corpora and transparent methodological caveats.

### 🔄 Data Processing & Inference Pipeline

1. **Ingestion & Canonicalization**:
   - `Analytics Jobs.csv` is parsed into canonical terms via token normalization (e.g. converting `Pytorch`, `py-torch`, and `pytorch` into canonical `PyTorch`, eliminating token artifacts).
   - Frequency counters calculate true posting prevalence:
     $$\text{Prevalence}(S) = \frac{\text{Postings containing } S}{N_{\text{total}} = 15,841}$$
2. **Topological Co-Occurrence Graphing**:
   - Pairwise intersection across all $15,841$ records yields real Jaccard association metrics:
     $$J(A, B) = \frac{|A \cap B|}{|A \cup B|}$$
   - Filters out spurious pairings with dynamic support thresholds to ensure production-grade edge connectivity.
3. **Dual ML Inference Gateways**:
   - **Junior Success (`POST /api/career-success/predict`)**: Scales five continuous dimensions (`maths_stats`, `dashboard_storytelling`, `ai_ml`, `big_data`, `coding`) through a trained `StandardScaler` to classify salary-hike likelihood with log-odds transparency.
   - **Senior Success (`POST /api/senior-success/predict`)**: Evaluates psychometric vectors across an ensemble of 100 estimators with tree-level feature variance.
4. **Grounded Copilot Reasoning**:
   - Queries are resolved deterministically against the in-memory dataset analytics cache—eliminating hallucinated statistics.

## 🚀 Quickstart & Installation

### Prerequisites
- **Node.js** >= 18.0.0
- **Python** >= 3.10.0
- **Git**

### 1. Clone the Repository
```bash
git clone https://github.com/saransh-ux/SkillX.git
cd SkillX
```

### 2. Backend Setup
```bash
cd backend

# Create and activate virtual environment
python -m venv .venv

# Windows (PowerShell)
.\.venv\Scripts\Activate.ps1
# Linux / macOS
source .venv/bin/activate

# Install dependencies
pip install -r requirements.txt

# Start FastAPI server
uvicorn app.main:app --port 8000 --reload
```
*Backend runs live at `http://localhost:8000` (Docs: `http://localhost:8000/docs`)*

### 3. Frontend Setup
In a new terminal window:
```bash
cd ..

# Install npm dependencies
npm install

# Start Vite dev server
npm run dev
```
*Frontend runs live at `http://localhost:5173`*

## 🔒 Fail-Safe Modes & Mock Safety

- **Default Live Mode (`VITE_DEMO_MODE=false`)**:
  - The UI connects directly to FastAPI. If the backend disconnects, silent mock masking is blocked. The application renders an explicit **`BACKEND CONNECTION ERROR`** diagnostic card showing endpoint, HTTP code, and retry actions without exposing internal stack traces.
- **Demonstration Mode (`VITE_DEMO_MODE=true`)**:
  - Enables offline simulations for environments without Python runtimes. A prominent **`DEMO MODE / MOCK DATA`** badge is displayed at all times.
